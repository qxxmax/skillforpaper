# SPS Seminar Talk Package (2026-08-13)

First worked example of **Part 6: present the toy**. It builds the evidence
package for a 20-minute specialist seminar — "SPS in the learned-sampler
lineage" — entirely from already-verified ledgers: lineage deltas D001-D004
from the Part 2 rerun and the July full rerun's landscape/funnel graphs.

What it demonstrates:

- the presentation contract fixes one core message and a claim-level cap
  before any slide exists;
- every slide headline is an assertion mapped to evidence; the unmeasured
  effect of SPS's drift parameterization appears as a boundary slide, not a
  hidden omission;
- figures carry provenance to the run that produced them;
- the QA bank answers the hard questions ("is it better than flows?") with
  the honest "not measured" where that is the truth.

Read in this order: `presentation_contract.md` → `slide_claim_map.csv` →
`figure_provenance.md` → `qa_bank.md`.
