here. Reports cite `EvidenceID`, not just `PaperID`. Every URL below was
actually visited in a logged call in `round_log.md`; no row rests on recall.

the arXiv API (`export.arxiv.org/api/query`), which returns the authoritative
title, author list, versioned ID, primary category, `journal_ref`, and DOI for

## Evidence Rules Applied

- `E_QUOTE` rows carry the focal paper's own lineage statements: these establish
  that a work is a predecessor, not that the work's metadata is correct.
- `E_DOI` / `E_ABSTRACT` rows carry the independent arXiv record: these establish
  identity (title, authors, ID) and topical fit.
- A predecessor is asserted only where both kinds of row exist. `E_METADATA_ONLY`
  and `C1` rows are not used as strong claim evidence.
- No screenshots were captured, so nothing here is offered as screenshot proof.
