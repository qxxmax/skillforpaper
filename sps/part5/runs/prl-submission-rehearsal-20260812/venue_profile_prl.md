# Venue Profile: Physical Review Letters

## Identity

- Venue: Physical Review Letters (APS)
- Track/section: Letters
- Guideline URL: <https://journals.aps.org/prl/authors> and
  <https://journals.aps.org/authors/length-guide>
- Guideline fetch date: 2026-08-12 (direct fetch bot-blocked; full page text
  retrieved via substitute search channel — see round_log.md call ledger)
- Deadline / submission window: rolling
- Expected decision timeline: no published guarantee; length pre-screening
  happens before review

## Format Rules

| item | value | source anchor |
|---|---|---|
| main-text limit | 3750 words AND ~4 journal pages — both binding | prl/authors "Letters (length limit: 3750 words)"; length-guide |
| word count includes | body text, displayed math (16 words/row single-column), figure captions, table text, footnotes | length-guide table |
| word count excludes | title, author list, abstract, acknowledgments, references | length-guide table |
| abstract | 600 characters including spaces | substitute channel; confirm at portal |
| End Matter | up to 2 pages of appendices after acknowledgments; does not count against core limit | prl/authors |
| waivers | 1/2-page or larger waivers by editor request; decisions not appealable | prl/authors |
| required template | REVTeX 4.2 with `prl` journal option | length-guide |

## Review Model

- Blind model: editor-mediated, reports private; single-anonymous by default
  (double-anonymous option: confirm at portal)
- Rebuttal window: responses to referee reports via resubmission letters, no
  fixed character limit
- Revision model: revise-and-resubmit rounds mediated by the editor

## Policy

- Checklist required: none (physics venue; apply this skill's manifest
  discipline instead)
- Code/data submission policy: Supplemental Material supported; confirm
  current data policy at portal
- Preprint (arXiv) policy: posting preprints is permitted (APS policy)
- Prior disclosure: submission asserts the work is not under consideration
  elsewhere; conference-proceedings overlap must be referenced

## Fit

- Scope-fit statement: PRL requires "brief accounts of highly important
  original research, which are complete and accessible for the general
  reader" (prl/authors) — the SPS story must be compressed to one
  broad-interest claim within 3750 words.
- Main risk at this venue: the length gate (pre-review shortening demands)
  and the broad-importance bar, given that the Part 2 review classifies SPS
  as an adaptation with a narrow correction-mechanism difference.
